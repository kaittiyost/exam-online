เริ่มอ่านเนื้อหาเช็กความพร้อม 
pdpa.หลักใหญ่ {
  ข้อมูลส่วนบุคคล = ระบุตัวบุคคลได้
  เก็บ = เท่าที่จำเป็น (ม.22)
  ยินยอม = ชัดแจ้ง + ถอนได้ง่าย (ม.19)
  ข้อมูลรั่ว → แจ้งสำนักงาน ≤ 72 ชม.
}
